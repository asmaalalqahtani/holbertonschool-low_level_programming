# C - More functions, more nested loops

More practice with functions, header files, and nested loops in C.

## Files
| File | Description |
|------|-------------|
| main.h | Header file with all function prototypes |
| _putchar.c | Writes a character to stdout |
| 0-isupper.c | Checks for an uppercase character |
| 1-isdigit.c | Checks for a digit (0 through 9) |
| 2-mul.c | Multiplies two integers |
| 3-print_numbers.c | Prints the numbers from 0 to 9 |
| 4-print_most_numbers.c | Prints the numbers from 0 to 9, except 2 and 4 |
| 5-more_numbers.c | Prints the numbers from 0 to 14, 10 times |
| 6-print_line.c | Draws a straight line |
| 7-print_diagonal.c | Draws a diagonal line |
| 8-print_square.c | Prints a square of # |
| 9-fizz_buzz.c | Prints the Fizz-Buzz sequence from 1 to 100 |
| 10-print_triangle.c | Prints a right-aligned triangle of # |
